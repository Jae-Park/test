# Ask Anything — 잡학 · 아이디어 아카이브

이 레포는 Claude Code를 "채팅처럼" 쓰되, **답변이 파일로 남는** 개인 지식 베이스다.
무슨 질문이든 받고, 답하면서 동시에 기록을 남긴다.

## 기본 동작
- 질문에 답할 때, 답변을 파일로도 저장한다. (대화로만 끝내지 않는다)
- 분류가 애매하면 `inbox/YYYY-MM-DD-제목.md` 에 저장.
- 글쓰기 관련이면 `writing/` 에 저장.
- 특정 주제가 반복되어 덩어리가 커지면 `topics/<주제>/` 로 승격시킨다.
  (미리 폴더를 많이 만들지 말고, 자라는 대로 분화한다)

## 이어쓰기 규칙 (가장 중요)
- 새 주제면 새 파일.
- **이미 다룬 주제면 새 파일을 만들지 말고 기존 파일에 이어붙인다.**
  1. 먼저 관련 파일을 검색한다 (제목 + 내용 grep)
  2. 있으면 그 파일을 열어 날짜 헤더(`### YYYY-MM-DD`)를 찍고 그 아래에 추가
  3. 없을 때만 새 파일 생성
- 이 규칙이 없으면 같은 주제로 파일이 수십 개 생겨 난장판이 된다.

## 인덱스(README) 갱신
- 새 파일을 만들면 `README.md` 목차에 한 줄 추가한다.
  형식: `- [제목](경로) — 한 줄 설명`

## 글쓰기 파일 포맷 (`writing/`)
```
# <제목>

## 💡 처음 떠오른 생각 (YYYY-MM-DD)
...

## 🎯 가능한 앵글
- ...

## ✍️ 메모 / 초안
### YYYY-MM-DD
...

## 🔗 관련
- (관련 파일 링크)
```

## 톤
- 잡질문엔 길게 늘이지 말고 핵심부터. 더 깊게 원하면 그때 판다.
- 사실과 의견(추정/전망)을 섞지 말 것. 불확실하면 불확실하다고 표시.

## 마무리 (커밋)
- 작업이 끝나면 변경분을 커밋한다. (커밋해야 GitHub에 남는다 — 컨테이너는 일회용)
- 커밋 메시지는 한 줄 요약으로 간결하게.
